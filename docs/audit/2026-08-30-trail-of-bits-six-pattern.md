### 1. Arbitrary CPI — pass

No `invoke` / `invoke_signed`. Every SPL transfer uses `anchor_spl::token::transfer` with `token_program: Program<'info, Token>` (`create_market`, `place_bet`, `resolve_market`, `claim_winnings`). Program id is typed, not caller-chosen.

### 2. Improper PDA validation — pass

No `create_program_address`. Config, rake, market, vault, and user position use Anchor `seeds` + stored bump (`bump = config.bump`, `market.bump`, `market.vault_bump`, `user_position.bump`). Inits persist `ctx.bumps.*`. Vault signer seeds are `[b"market", market_id, market.bump]` (vault authority is the market PDA).

### 3. Missing ownership check — pass

Program accounts go through `Account<'info, T>` (discriminator + owner). The only `UncheckedAccount`s are `founder_token` and `creator_token` in [`resolve_market.rs`](../../programs/fomo-pnl/src/instructions/resolve_market.rs). The handler checks `info.owner == Token` **before** `TokenAccount::try_deserialize`, then mint and token-owner. That is the required order for pattern 3.

### 4. Missing signer check — pass

Every privileged or user action is `Signer<'info>` plus a key constraint (`config.admin`, `config.resolver`, `rake.owner`, `rake.founder`, or the bettor/claimant). No authority path is a bare `AccountInfo`.

### 5. Sysvar account check — pass

Time is `Clock::get()?` only (`create_market`, `place_bet`, `resolve_market`, `cancel_market`). No user-supplied clock/sysvar account.

### 6. Instruction introspection — pass

No `load_instruction_at`, `load_current_index`, or relatives.
