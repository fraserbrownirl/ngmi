# Design refs (locked before CSS)

## Visual thesis
Newsprint tote board: cream stock, iron-gall ink, one acid-green ticket stamp. Ranked rows like a racing form — not a SaaS card grid.

## Content plan
1. Masthead + live “Top 50 · all-time PnL”
2. Pick a row → $X, datetime, Solana pot
3. Market slip: YES / NO stake, live PnL vs $X, claim

## Motions (Animista only)
1. `slide-in-left` — board row entrance
2. `pulsate-fwd` — YES / NO / claim hover

## Ref 1 — leaderboard
Source: Will Loveland, BetDEX case study (player leaderboards / event-first tote).
https://loveland.design/case-study/betdex
Copied: dense rank column, handle left, numeric PnL right-aligned tabular figures, hairline rules, no cards.

## Ref 2 — bet / stake
Source: Smarkets exchange betslip (Matthew Allen) — stake, return, outcome in one slip.
https://matthewallen.design/smarkets-betting-exchange
Copied: two-outcome columns, stake field flush to the action, live payout math, no decorative chrome.
